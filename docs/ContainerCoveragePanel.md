# 容器覆盖范围面板 (Container Coverage Panel)

## 概述

显示文档中所有已注册容器的覆盖范围，以纵向字符序列 + 竖条的方式可视化。帮助开发者理解文档结构、调试容器布局。

## 面板位置

左侧边栏，与 DOM 树面板通过 Tab 切换。

## 数据来源

- 通过 `Editor.getRegisteredConfigs()` 获取所有已注册的容器配置
- 通过 `Editor.querySelectorAll()` + `Editor.getElementPosition()` 定位每个容器元素
- 使用 `Editor.buildIndex()` 一次性构建索引（O(N) 优化）
- 通过 `html` prop 响应式依赖，编辑器内容变化时自动刷新

## 可视化设计

### 字符序列（左侧）
- 文档文本按字符逐行纵向排列
- 每行显示：行号 + 字符（`\n` 显示为 `↵`，空格显示为 `·`）
- 行高 14px

### 容器竖条（右侧）
- 每个容器渲染为一条连续的纵向竖条
- 竖条从容器 start 到 end 精确匹配对应的文本行
- 竖条宽度 20px，带圆角
- 竖条颜色按容器类型区分（bold=红色, italic=紫色 等）
- **竖条内文字**：竖条高度 ≥42px 时，显示竖排容器名称文字（writing-mode: vertical-rl）
- 不同类型的竖条使用不同颜色，配合图例对照

### 列分配规则（关键算法）
1. **最长容器优先**：按跨度降序排列，最长容器分配到最左侧列
2. **不重叠**：同一列内的容器不能在垂直方向上重叠
3. **同类型优先同列**：相同 configName 的容器优先分配到同一列
4. **贪心分配**：对每个容器，找到最左可用列（同类型已占用的列优先）

### 折叠功能
- 连续 ≥3 个没有容器边界（无容器 start/end）的字符行可以折叠
- 折叠后显示为一行，标注折叠行数（如 `5 行`）
- 点击折叠行可展开，展开后末尾显示"收起"按钮
- 折叠行在行号和文字列有特殊样式（如浅灰背景、省略号标记）
- 容器竖条在折叠区域压缩显示，视觉高度随之缩小

### 颜色图例
- 面板顶部显示所有实际存在的容器类型
- 每种类型显示：色块 + 名称
- 保持注册顺序

## 交互

### 点击竖条 → 选中容器
- 点击任意竖条，高亮显示（ring + 亮度变化）
- 底部弹出操作栏，显示：
  - 容器类型名称 + 颜色标记
  - 位置范围 `[start, end]`
  - 跨块数（fragmentCount > 1 时）
  - 文本内容预览
  - 操作按钮：选中、移除、取消

### 选中
- 在编辑器中高亮选中容器对应的文本

### 移除
- 调用 `Editor.removeStyle()` 移除该容器的样式包裹

### 取消
- 取消选中状态

## 统计摘要

面板顶部显示：
- 容器类型数
- 容器总数
- 跨块数（fragmentCount > 1 的容器数）
